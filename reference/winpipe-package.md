# winpipe: Interface to Windows Named Pipes

Provides support for Windows Named Pipes for inter-process communication
through the 'Win32' C++ API. Allows to create, connect, disconnect, read
from, and write to server and client pipes as standard R connections.
Includes convenience utilities to parse and build Access Control List
(ACL) security descriptors. HTTP requests are indirectly supported via
background relay servers.
